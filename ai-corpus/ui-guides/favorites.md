# Favorites

This is source content for the AI Assistant's knowledge base (see `scripts/build-ai-corpus.mjs`),

describe exactly what a user sees and clicks, not just what the feature does. Regenerate this file

would make the description below inaccurate.

Favorites is a page for pinning specific owned games into your own ordered list, separate from
your full library.

## Page layout and header

The header shows the page title, a "N favorite(s)" (or "No favorites yet") subtitle, and a plus-icon
button that opens the "Add game manually" dialog for adding a game by its Steam App ID. Below the
header are two tabs: "All Games" and "Favorites".

## Adding games from All Games

The "All Games" tab is a grid of your owned games (with a sort dropdown above it). Each card shows
the game's thumbnail and name, plus a small icon-only button in the corner: a plus icon if it isn't
favorited yet, or a checkmark if it already is — clicking it toggles favorite membership.

## Managing your favorites list

The "Favorites" tab shows your favorited games as a grid of draggable cards, each with the game's
thumbnail, name, and a remove button (an X icon) that takes it out of the list. Cards can be
dragged to reorder — dropping one immediately saves the new order. While on this tab (and it has at
least one favorite), a "Clear" button appears next to the tabs; clicking it opens a confirmation
dialog ("Clear all favorites? — This will remove all N games from your favorites list.") before
wiping the whole list.
