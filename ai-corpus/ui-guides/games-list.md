# All Games (Games List)

This is source content for the AI Assistant's knowledge base (see `scripts/build-ai-corpus.mjs`),
generated by reading the actual `src/features/games-list/` component code so the AI Assistant can
describe exactly what a user sees and clicks, not just what the feature does. Regenerate this file
(via the `/generate-ui-guide games-list` skill) whenever this feature's UI changes in a way that
would make the description below inaccurate.

This is the default page you land on after signing in, listing your entire Steam library. It's
also where idling actually starts and stops, and the entry point for opening a game's achievements.

## Page layout and header

The header shows "Games", a "N games" count, a sort dropdown, and a circular refresh button. If
your Steam profile or game details appear to be private, a warning banner appears below the header
("Some game data may be missing — Your Steam profile or game details appear to be set to private,
so playtime, recently played, and some games may be incomplete.") with two buttons: "Change privacy
settings" (opens your Steam profile's privacy settings in your browser) and "Add my own API key"
(opens the Settings modal's General tab).

## Discovery carousels

Above the main library grid are up to two horizontally-scrolling carousels (each can be turned off
in settings): "Recommended" (games you own with zero playtime) and "Recently Played" (your
most-recently-played games, newest first). Cards inside a carousel behave exactly like library
cards below — the same idle toggle and achievements button work here too.

## The game grid, idling, and achievements

Below a "All Games" heading, every owned game appears as a card with its thumbnail, name, and two
small icon-only buttons: a play/stop icon that starts or stops idling that specific game (a live
timer overlays the thumbnail while it's idling), and a trophy icon that opens the Achievement
Manager overlay for that game. This is the only place idling is actually started or stopped by
picking individual games — the Idling page itself only shows a read-only, filtered view of whatever
is currently running.
