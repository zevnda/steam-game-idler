# Sidebar

This is source content for the AI Assistant's knowledge base (see `scripts/build-ai-corpus.mjs`),
generated by reading the actual `src/shared/components/dashboard/Sidebar.tsx` and
`SidebarItem.tsx` so the AI Assistant can describe exactly what a user sees and clicks, not just
what the feature does. Regenerate this file (via the `/generate-ui-guide sidebar` skill) whenever
this UI changes in a way that would make the description below inaccurate.

The sidebar is the app's main navigation, always visible on the left of every dashboard page. It
can be collapsed to a narrow icon-only rail (toggled from the titlebar's sidebar icon, or Ctrl+W) —
collapsed items show just their icon, with the label available as a hover tooltip instead.

## Navigation sections

Three grouped sections, each with a small uppercase header (hidden while collapsed):

- **Games** — Games, Idling, Favorites, Free Games.
- **Automation** — Card Farming, Achievement Unlocker, Automatic Idler.
- **Misc** — Inventory Manager.

A nav item's icon pulses (and its label turns accent-colored) while that feature has something
actively running: Idling pulses while any game is idling, Card Farming while a farming cycle is
active, and Achievement Unlocker while it's running — so you can tell an automation is live from
anywhere in the app, not just its own page. Free Games' icon turns gold whenever there's at least
one unowned free game currently claimable.

## Ads

In production, non-Pro accounts see a small ad slot near the bottom of the sidebar, above the
footer. Subscribing removes it.

## Footer

At the bottom, above a divider:

- **Plan row** — shows your current tier ("Plan" label plus a tier badge). For Casual subscribers,
  this row is clickable and opens the upgrade screen scrolled to the Gamer tier; for Free and Gamer
  accounts it's a static label (Free's upsell lives in the titlebar's "Go Pro" pill instead, and
  Gamer has nothing higher to upgrade to). Hidden entirely while the sidebar is collapsed.
- **Account switcher and Settings** — the account switcher (avatar, name, and a chevron) sits next
  to a gear icon button that opens the Settings modal. See the account-switcher UI guide for what
  clicking the switcher does.
