# Agent (Steam Sign-in) Sign-in Screen

This is source content for the AI Assistant's knowledge base (see `scripts/build-ai-corpus.mjs`),
generated by reading the actual `src/features/agent-sign-in/` component code so the AI Assistant
can describe exactly what a user sees and clicks, not just what the feature does. Regenerate this
file (via the `/generate-ui-guide agent-sign-in` skill) whenever this feature's UI changes in a way
that would make the description below inaccurate.

This is the screen shown after choosing "Steam Sign-in" on the sign-in landing page (or from "Add
another account" in the account switcher). It signs a Steam account in without needing a local
Steam client running.

## The combined credentials + QR layout

The screen shows two sign-in methods side by side in one card, separated by a vertical divider, and
both are live at the same time — completing either one signs you in, and completing one
automatically cancels the other:

- Left column, labeled "Sign in with account name": a username field, a password field, and a
  "Sign in" button. An incorrect attempt shows a "Couldn't sign in" alert above the fields with a
  reason ("Incorrect username or password.", a denial message, or a generic retry message).
- Right column, labeled "Or sign in with QR": a QR code (rendered as a real scannable code, not a
  placeholder image) with the instruction "Use the Steam Mobile app to sign in via QR code."
  underneath. If the QR challenge itself fails to load, this column shows an error message and a
  "Try again" button instead.

A back button (top-left, an arrow) returns to the sign-in method choice — but only while you're
still on the form itself; once you're into a Steam Guard code step, the guard code screen's own
"Cancel" button is the way back instead, since backing out silently at that point wouldn't clean up
the in-flight sign-in attempt.

## Entering a Steam Guard code

If Steam requires additional verification after submitting credentials, the screen switches to a
dedicated Steam Guard step (this replaces the whole two-column layout, not just one side):

- **Mobile authenticator code**: titled "Check your Steam Mobile app", asking you to "Enter the
  code from the Steam Mobile app."
- **Email code**: titled "Check your email", showing "We sent a code to <email>. Enter it below."
- **Confirmation-only**: titled "Confirm this sign-in", showing just a spinner and asking you to
  approve the request in the Steam Mobile app — there's no code to type here, only a "Cancel"
  button while you wait.

For the two code-entry variants, the code field is a 5-character one-time-code input (one box per
character). Entering an incorrect code shows "That code wasn't correct. Please try again." above
the input and marks it invalid. The "Verify" button stays disabled until all 5 characters are
entered, and shows a loading state while submitting. A "Cancel" button below it aborts the sign-in
attempt entirely and returns you to the form.

## What happens on success

A successful sign-in (from either the credentials form or the QR code) shows a full-screen spinner
briefly, then navigates straight to the dashboard's games page — there's no separate "success"
screen to click through.
