# Legacy (Local Steam Client) Sign-in Screen

This is source content for the AI Assistant's knowledge base (see `scripts/build-ai-corpus.mjs`),
generated by reading the actual `src/features/local-sign-in/` component code so the AI Assistant
can describe exactly what a user sees and clicks, not just what the feature does. Regenerate this
file (via the `/generate-ui-guide local-sign-in` skill) whenever this feature's UI changes in a way
that would make the description below inaccurate.

This is the screen shown after choosing "Legacy Sign-in" on the sign-in landing page (or from "Add
another account" in the account switcher). It picks which Steam account already saved on this
device to use — it requires a real, currently-running local Steam client, and is Windows-only.

## Choosing an account

The card, titled "Choose an account", shows every Steam account currently saved on this device as a
row of square avatar tiles (your persona name underneath each). Clicking a tile selects it — the
selected tile's avatar gets a blue-to-violet gradient frame around it. If more accounts are saved
than fit on screen, the tile area scrolls independently rather than growing the whole card.

Below the tiles are two buttons: "Continue" (disabled until an account is selected) and a circular
refresh button for re-scanning this device's saved accounts. If a selected account's profile
details couldn't be loaded, a warning banner appears above the tiles; if continuing with the chosen
account fails, a red error alert appears below them instead.

If no Steam accounts are found on this device at all, the card shows: "No Steam accounts were found
on this device. Sign into the Steam client at least once, then refresh." A back button (top-left)
returns to the sign-in method choice — hidden while an account switch is actually in progress, so
backing out mid-request can't leave things in a stranded state.

## What happens on continue

Choosing "Continue" may switch which account the local Steam client itself is signed into (if it
wasn't already the one you picked) before finishing sign-in — a brief spinner replaces the whole
screen while this happens, then you're taken straight to the dashboard's games page.
