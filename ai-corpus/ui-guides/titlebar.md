# Titlebar

This is source content for the AI Assistant's knowledge base (see `scripts/build-ai-corpus.mjs`),
generated by reading the actual `src/shared/components/titlebar/` component code (plus the
`UpdateButton`/`GoPro` buttons it mounts) so the AI Assistant can describe exactly what a user sees
and clicks, not just what the feature does. Regenerate this file (via the `/generate-ui-guide
titlebar` skill) whenever this UI changes in a way that would make the description below
inaccurate.

The titlebar spans the full width of the top of the window and is the app's only way to move,
minimize, maximize, or close it, since the window itself has no OS-drawn title bar. It's present on
every screen, including sign-in.

## Left side

Shows the app logo and "Steam Game Idler" wordmark, sized to match the sidebar's current width so
it stays visually anchored above it. On dashboard pages there's also a sidebar-toggle icon button
next to it (switches between an open and collapsed rail icon). A "Go Pro" pill appears here for
free-tier users only — an animated blue border, "Support Steam Game Idler" copy (hidden on narrow
windows), and a white "Go Pro" badge; clicking it opens the upgrade screen. Casual and Gamer
subscribers don't see this pill — their upgrade path is the "Plan" row in the sidebar instead.

## Right side

From left to right, when present:

- **Update button** — a circular down-arrow icon, shown only when an update is ready. Clicking it
  downloads and installs the update.
- **AI Assistant** — a robot icon (dashboard pages only) that opens the AI Assistant chat overlay.
  Visible to every tier — free-tier accounts just get a lower daily message cap, not a locked
  button.
- **Help Desk** — a headset icon that opens the live-chat support widget; a small red dot appears
  on it when there's an unread message. This button is Casual-tier and above only — it doesn't
  render at all on the free tier.
- **Notifications** — a bell icon with a red badge showing the unseen count. Clicking it opens a
  panel listing recent app notifications (each with a title, message, and relative timestamp), with
  a "Mark all as read" link at the top when there's anything to clear. An empty state reads "No
  notifications yet."
- **Menu** — a chevron-in-square icon opening a dropdown with: "Documentation", "Report an issue",
  "Feature request", "Join our Discord", "Changelog" (opens the changelog dialog), and — only on
  builds that support self-updating — "Check for updates".
- A vertical divider, then the three window controls: minimize, maximize/restore, and close (close
  turns red on hover).

## Search bar

Below the main row, a global search bar spans the titlebar on pages that support it — see the
global-search UI guide for how that works.
