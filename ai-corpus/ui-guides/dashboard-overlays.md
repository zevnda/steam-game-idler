# Dashboard Overlays (Changelog, Steam Warning, Banner)

This is source content for the AI Assistant's knowledge base (see `scripts/build-ai-corpus.mjs`),
generated by reading the actual `src/shared/components/ChangelogModal.tsx`,
`SteamWarning.tsx`, and `Banner.tsx` so the AI Assistant can describe exactly what a user sees and
clicks, not just what the feature does. Regenerate this file (via the `/generate-ui-guide
dashboard-overlays` skill) whenever this UI changes in a way that would make the description below
inaccurate. These three are unrelated app-wide overlays grouped here only because each is too small
for its own guide.

## Changelog

Opened from the titlebar Menu's "Changelog" item. A modal showing the app's changelog for your
current version, loaded from steamgameidler.com in an embedded frame (not maintained locally) — a
brief spinner shows while it loads. The footer has a "Star on GitHub" button and a "Changelog"
button that opens the full changelog page in your browser. A close button sits in the header.

## Steam Warning

An undismissable modal that appears if the app detects your local Steam client has closed while a
Legacy Sign-in (CLI-mode) account needs it — CLI-mode automations genuinely can't function without
a real running Steam client, so this can't be closed or worked around. It reads "Notice — Steam is
closed. Please relaunch Steam to continue." with a "Continue" button that launches Steam. The modal
closes itself automatically once Steam is detected running again.

## Banner

A bottom-of-screen banner strip, shown at most one at a time (an urgent system alert always wins
over a promotional one). Two visual styles:

- **Alert banners** (danger/warning/info/success) — a slim colored strip with an icon, a short
  message, an optional CTA button, and a close (X) button.
- **Promo banners** — a taller, more decorative strip with a background gradient, an optional
  artwork image, animated shooting-star/shimmer effects, a title and message, a CTA button, and a
  close button.

Dismissing either plays a brief exit animation before it disappears; a dismissed banner won't
reappear on its own.
