## Adding games to the queue

Open the Achievement Unlocker page from the sidebar. It has a "Browse" tab (pick games from your
library to add) and a "Queue" tab (games waiting to be unlocked, shown as a grid of game cards with
their cover art). Adding a game from Browse puts it into the Queue.

## Reordering achievements and choosing unlock order

Each game card in the Queue tab has two small icon buttons in its top-right corner: an "Edit unlock
order" button (a sort/arrows icon) and a remove button (an X icon). Clicking the sort icon opens a
full-screen order editor for that specific game.

Inside the order editor, each achievement appears as its own row containing, from left to right:

- A checkbox — unchecking it skips that achievement (it stays in the list, greyed out with a
  "Skipped" label, but won't be unlocked).
- The achievement's icon image.
- The achievement's name, its description below it, and (if available) a small rarity percentage
  badge showing how many other Steam players have it.
- A grabber icon on the far right — six dots arranged in two rows. Click and hold this handle to
  drag the achievement up or down in the list. The order you drop it in is the exact order Steam
  Game Idler will unlock that game's achievements in.

At the top of the list there's also a delay control for how long to wait before the very first
achievement unlocks, and each row's connecting space between achievements lets you set a delay
before that specific achievement unlocks relative to the one before it — this is what makes unlocks
land with natural-feeling gaps instead of firing all at once.

The order editor's header (top of the screen) has a close button (X, top-left) and the game's name.
On the top-right: a "Reset" button (red) that clears any custom order/skip/delay changes back to
default, and an "Import" button that pulls the exact achievement order and delay timings from any
public Steam profile that already has them (Gamer-tier subscribers only — Casual and Free-tier
accounts see this button with a small tier badge instead, which opens the upgrade screen).

Changes made in the order editor are saved via a "Save" button at the bottom of the screen once
you're done arranging things — nothing is applied until you save.
