# Global Search

This is source content for the AI Assistant's knowledge base (see `scripts/build-ai-corpus.mjs`),
generated by reading the actual `src/shared/components/search/GlobalSearchBar.tsx` and
`GlobalSearchModal.tsx` so the AI Assistant can describe exactly what a user sees and clicks, not
just what the feature does. Regenerate this file (via the `/generate-ui-guide global-search` skill)
whenever this UI changes in a way that would make the description below inaccurate. The keyboard
shortcut to open it (`/`) is documented in the Settings/Keybinds guide.

Global search is a "search my library" affordance shown in the titlebar on pages that have
something searchable — it isn't available on every page (idling, free games, and the sign-in
screens don't show it at all, since a hidden affordance is clearer than one that looks clickable
but does nothing).

## The titlebar search bar

On a wide window, this renders as a pill in the center of the titlebar reading "Search" (or your
current search text, with a small clear/X button once you've typed something). On a narrow window,
it collapses to a small circular search-icon button instead, to avoid colliding with the titlebar's
other buttons. Either form opens the same search modal when clicked.

## The search modal

A modal drops down from the top of the screen with a large search input (auto-focused) and a clear
button once you've typed anything. What shows below the input depends on what you've typed:

- **While typing** — up to 8 live-matching games from your library, each row showing the game's
  thumbnail and name. Clicking a row (or navigating to it with the arrow keys and pressing Enter)
  commits that name as your search text for whichever page you opened this from, and closes the
  modal. If nothing matches, it shows "No results found."
- **With nothing typed** — a "Recent searches" list of your past search terms instead, each with
  its own small remove button. If you have no recent searches, it shows "No recent searches."

Arrow keys move a highlight up and down through whichever list is showing; Enter commits the
highlighted row (or, if nothing's highlighted, your raw typed text). Escape clears the current text
without closing the modal first.

Committing a search only sets a filter on the page's own game list — it's local to whichever
feature you searched from (Games, Favorites, Card Farming, Achievement Unlocker, or Auto Idle all
filter their own "browse" tab; the curated list/queue tab on those pages is deliberately left
unfiltered).
