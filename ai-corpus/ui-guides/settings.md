# Settings

This is source content for the AI Assistant's knowledge base (see `scripts/build-ai-corpus.mjs`),
generated by reading the actual `src/features/settings/` component code so the AI Assistant can
describe exactly what a user sees and clicks, not just what the feature does. Regenerate this file
(via the `/generate-ui-guide settings` skill) whenever this feature's UI changes in a way that
would make the description below inaccurate.

The Settings modal is a full-screen overlay opened from anywhere in the dashboard (a gear icon in
most feature headers, or the sidebar). It has a fixed left-hand navigation column listing every
category, and a scrollable content column on the right. Each category's content starts with a
small "Settings ›" breadcrumb above its own title. At the bottom of the nav column are social links
and the installed app version.

Card Farming, Achievement Unlocker, Inventory Manager, and Free Games each have their own settings
category here too, but their controls are documented in those features' own UI guides, not
repeated here.

## General

Shows an account header (avatar, display name, and either a Username or Steam ID field depending on
sign-in mode), then:

- **Language** — a dropdown to change the app's display language, with a "Help translate SGI" link
  to the project's Crowdin page.
- **Always online** (Legacy Sign-in accounts only) — periodically refreshes your Steam status so
  you don't appear away while idling.
- **Online status** and **Custom status while idling** (Steam Sign-in accounts only) — a dropdown
  of Steam presence states (Online, Busy, Away, Snooze, Looking to Trade, Looking to Play,
  Invisible, Offline), and a text field to replace the "Playing [game]" text friends see while
  idling with your own message. The status picker is free for everyone; the custom message field
  has its own "Save"/"Clear" buttons and is Gamer-tier only — on lower tiers those buttons still
  look normal but open the upgrade screen instead of saving (a "GAMER" badge sits next to the
  label).
- **Show games only** (Steam Sign-in accounts only) — hides DLC, soundtracks, videos, and tools
  from your library, showing only owned/family-shared games.
- **Run at startup**, **Start minimized**, **Close to tray** — three toggles controlling how the
  app launches and behaves when closed.
- **Automatically update games list** — silently refreshes your library in the background. Casual
  tier and above; below that it stays a real, clickable switch with a "CASUAL" badge that opens the
  upgrade screen instead of turning on.
- **Steam Web API key** — a password-style text field to override the app's built-in API key, with
  "Clear" and "Save" buttons.

## Subscription

Shows your subscription status (a tier badge, billing email, and renewal or cancellation date) with
a "Manage subscription" button (opens your billing portal) and, for Casual subscribers, an
"Upgrade" button. Below that is a license key field: if you have one activated, it's shown masked
with "Copy" and "Clear" buttons; if not, there's an input to paste one and an "Activate" button.
Activating a key already active on another device shows a confirmation dialog first ("Transfer this
license key? — This license key is already active on another device. Activating it here will
deactivate it there.").

## Customization

Has toggles for "Disable tooltips" (hides hover tooltips app-wide) and showing/hiding the games
list's "Recommended" and "Recently Played" carousels — all free for everyone. Below that:

- **Font** — a dropdown of over 20 fonts, each previewed in its own typeface in the list.
- **Background image** — a "Choose image" button (opens a file picker for PNG/JPG/WEBP/GIF) and a
  "Clear" button.
- **Theme** — a row of small color swatches (Default, Blue, Red, Purple, Pink, Orange, Black,
  White) to pick as the app's color theme.

Font and Background are Casual-tier gated (a "CASUAL" badge appears next to their labels); Theme's
swatches are all visible and clickable regardless of tier, but selecting anything other than
Default on a lower tier opens the upgrade screen instead of applying it.

## Steam Credentials

Lets you save Steam Community cookies once so Card Farming and Inventory Manager don't need them
re-entered separately. For a Gamer-tier Steam Sign-in account, this shows a plain note instead:
"Not needed. This account signs in via Steam and gets its Steam Community session automatically."
Everyone else sees the same Automatic/Manual connect panel used on the Card Farming and Inventory
Manager pages, plus a "Learn more" link.

## Game Settings

A two-column layout: a searchable, scrollable list of every owned game on the left (a small dot
marks any game with a custom override), and fields on the right grouped into three bordered
sections — Playtime, Idling, and Achievement Unlocker. A toggle button next to the search box
filters the list to only customized games.

With no game selected, the right side shows account-wide defaults: "Max playtime (all games)" and
"Max idle time (all games)" (0 means unlimited). Selecting a game from the list switches to that
game's own overrides instead — "Max playtime", "Max idle time", and "Max achievement unlocks" for
that specific game, each overriding the account-wide value when set above 0. A note under each
section explains its scope (e.g. the idle-time cap doesn't apply to achievement unlocking, which
has its own separate cap).

## Keybinds

A read-only reference list (not an editor — no shortcut here can be remapped) of every keyboard
shortcut the app supports, grouped into "Zoom" (zoom in/out, reset zoom, with scroll-wheel
alternatives shown) and "Navigation" (next/previous page, open search, toggle settings, toggle
sidebar) sections.

## Debug

Shows the app version, OS, and whether this is a portable or installed build, followed by a row of
buttons: "View log file", "Open settings file", "Export settings" (copies your settings to the
clipboard), "Clear logs" (red), "Reset settings" (red), and "Clear data" (red). Below that is a
scrollable, monospace live view of the app's most recent log lines (error lines highlighted in
red).

"Reset settings" and "Clear data" both open a confirmation dialog before acting:
- **Reset settings** resets your Steam Web API key override and, if signed in, this account's
  achievement unlocker, inventory manager, card farming, and free games settings back to their
  defaults — your signed-in accounts stay signed in.
- **Clear data** signs every account out, stops any running automation, clears logs, and wipes
  locally-stored app data on this device (recent searches, inventory locks, etc.) — this can't be
  undone.
