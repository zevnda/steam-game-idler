## Connecting before you can farm

The first time you open Card Farming (or whenever your Steam Community session needs
re-establishing), the page shows a connect panel instead of any game list. It offers an
"Automatic" tab ("Signs in to Steam Community automatically to check for drops.") and a "Manual"
tab for pasting your own Steam cookies — the manual option works on every tier, while the
automatic one requires a Gamer subscription. A "Learn more" link and a note about previously saved
credentials also appear here. Connecting only proves your session works and loads the games list —
it doesn't start farming by itself.

## Starting and stopping

Once connected, the header shows "Not farming" or "Farming N games", a "Start" button (a filled
play icon, disabled if there are no eligible games with drops), a settings (gear) icon that opens
Card Farming's tab in the Settings modal, and — once running — the Start button is replaced by a
red "Stop farming" button.

## Browsing games with drops

The "Games With Drops" tab lists every owned game that still has card drops remaining, as a grid of
cards showing the game's thumbnail, name, and a "N drops remaining" count. Each card has two
icon-only buttons: a ban icon that blacklists the game (removing it from this list permanently
until un-blacklisted from the Blacklisted tab) and a plus/checkmark icon that adds or removes it
from your whitelist.

## Using the whitelist and blacklist tabs

The "Whitelisted" tab shows games you've explicitly restricted farming to — if this list is empty,
farming considers every owned game with drops; adding at least one game here narrows it to just
those. Each card has a remove (X) button. When non-empty, a "Clear" button next to the tabs opens a
confirmation dialog before wiping the whole whitelist ("This will remove all N games from the card
farming whitelist. Farming will go back to considering every owned game with drops.").

The "Blacklisted" tab shows games you've excluded from ever being farmed, each with its own remove
button to un-blacklist it, and the same kind of "Clear" confirmation for wiping the entire
blacklist.

## Watching an active farming session

While farming is running, the page shows a live progress view instead of the tabs:

- An "active" section (title switches between "Farming (N)" while actually farming card drops, or
  "Building playtime (N)" while a game is still accumulating the playtime needed before it becomes
  farmable) — a grid of cards with cover art, a progress bar, and either an "N drops remaining"
  label or an "Xh / Yh until farmable" label depending on which phase that game is in.
- An "Up next (N)" list of games waiting their turn, each showing either "still accumulating
  playtime" progress or "Waiting its turn."
- A "Completed this session" list once any games finish — each row shows a checkmark for a normal
  completion (no drops left), or an info icon with an explanation for anything else: still inside
  Steam's refund window (with the date farming resumes), or removed from the whitelist for having
  no playtime / already having playtime.

Once a session ends, this view stays visible with a "Done" button at the bottom — dismissing it (or
starting a new session) is what actually clears it from view.

## Settings

Card Farming's settings tab (opened via the gear icon, or from the app's Settings modal) has:

- **Hours until farmable** — a number field for how much playtime a game needs before it's
  considered ready to farm (0 skips straight to farming).
- **Farm multiple games at once** (Beta badge) — a toggle to farm up to 32 games concurrently
  instead of one at a time; turning it on for the first time shows a one-time notice dialog warning
  that farming multiple games simultaneously can slow down how quickly cards drop per game.
- **Automatically farm cards** — a toggle that periodically checks for games with drops and starts
  farming them on its own; Gamer-tier only — on lower tiers this stays a real, clickable switch with
  a "GAMER" tier badge that opens the upgrade screen instead of turning on.
- **Skip refundable games** (Beta badge, agent-mode accounts only) — skip games still inside
  Steam's 14-day/under-2-hours refund window.
- **Skip unplayed games** and **Unplayed games only** — two mutually exclusive toggles (turning one
  on turns the other off).
- **Start another task when done** — a toggle that, when on, shows two buttons ("Achievement
  Unlocker" / "Auto Idle") to pick which automation starts automatically once farming finishes.
