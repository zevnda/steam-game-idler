# Idling

This is source content for the AI Assistant's knowledge base (see `scripts/build-ai-corpus.mjs`),
generated by reading the actual `src/features/idling/` component code so the AI Assistant can
describe exactly what a user sees and clicks, not just what the feature does. Regenerate this file
(via the `/generate-ui-guide idling` skill) whenever this feature's UI changes in a way that would
make the description below inaccurate.

The Idling page is a read-only, grouped view of whatever games are currently idling — it's not
where idling is started. Starting or stopping an individual game's idling always happens from its
card on the All Games page (or from Auto Idle/Card Farming/Achievement Unlocker directly); this
page just shows the combined result and gives you a way to stop things in bulk.

## Page layout and header

The header shows "Idling", a "N games idling" (or "No games idling") subtitle, and — only when at
least one game is idling — a red "Stop all" button that stops every idling game across every
feature at once.

## Grouped sections

Currently-idling games are grouped into sections by whichever feature actually started them:
"Manually idled" (started directly from a game's card on the Games page), "Card Farming",
"Achievement Unlocker", "Auto Idle", or a generic "Other" bucket for anything that doesn't fit
those. Each section shows its own game count and, for every section except "Other", its own
"Stop" button that stops just that section's games (a red button next to the section title). Games
within a section render as the exact same cards used on the Games page — thumbnail, name, a live
idle timer overlay, and the same stop/achievements icon buttons — so a game can also be stopped
individually right from this page.

If a game happens to be claimed by more than one feature at once, it's shown under whichever
section has precedence, but "Stop all" still always covers it regardless of which section it's
displayed under.
