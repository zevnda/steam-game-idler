# Sign-in Landing Page

This is source content for the AI Assistant's knowledge base (see `scripts/build-ai-corpus.mjs`),
generated by reading the actual `src/features/sign-in-landing/` component code (plus the shared
`AuthLayout`/`SignInHero` chrome it renders inside) so the AI Assistant can describe exactly what a
user sees and clicks, not just what the feature does. Regenerate this file (via the
`/generate-ui-guide sign-in-landing` skill) whenever this feature's UI changes in a way that would
make the description below inaccurate.

This is the very first screen shown when the app launches with no account signed in (`/`), and also
the first step of the "Add another account" flow from the account switcher.

## Overall layout

The screen splits into two columns. The left column shows the app logo (with a glowing cyan/violet
ring behind it) and the sign-in card itself. The right column shows a marketing panel: a headline
and subtitle over a continuously auto-scrolling wall of game cover art, with a screenshot of the
app layered on top. In the bottom-left corner, a language switcher sits next to a "Need help?" link
that opens the sign-in documentation page in your browser.

## Choosing a sign-in method

The card, titled "Sign in to Steam Game Idler", offers two buttons stacked vertically:

- **"Steam Sign-in"** (primary, filled) — the recommended method; doesn't require a local Steam
  client. Selecting it goes to the Steam Sign-in screen (username/password or QR code).
- **"Legacy Sign-in"** (secondary, outlined) — requires a real, currently-running local Steam
  client. Selecting it goes to the local account picker. This button is hidden entirely on Linux,
  which has no local-Steam-client sign-in path at all.

When shown inside "Add another account" (not the initial landing page), these buttons can be
restricted:
- If a local (CLI-mode) account is already signed in, "Legacy Sign-in" is a plain disabled button
  with a note underneath: "A local Steam client account is already signed in — only one can be
  signed in at a time."
- If you've hit your subscription tier's limit on concurrent Steam Sign-in accounts, "Steam
  Sign-in" either becomes a plain disabled button (if you're already on the highest tier) or stays
  a real, clickable, slightly dimmed button with a "GAMER" tier badge that opens the upgrade screen
  instead of starting sign-in — either way with an explanatory note underneath.

On the very first sign-in (not the "Add another account" flow), a footnote below the buttons reads:
"By continuing, you agree to the Terms of Service and acknowledge that you have read our Privacy
Policy," with both terms as clickable links opening the respective pages in your browser.
