# Auto Idle

Auto Idle is the page for building a queue of games that start idling automatically whenever the
app launches, rather than needing to be started manually each time.

## Page layout and header

The header shows the page title, a "N games queued" (or "No games queued") subtitle, a "Start"
button (a filled play-triangle icon), and a plus-icon button that opens the "Add game manually"
dialog (add a game by its Steam App ID when it doesn't show up automatically — has a Name field and
an App ID field, and warns if that App ID is already in the list). "Start" is disabled until at
least one queued game is enabled, and immediately begins idling every currently enabled game in the
queue.

Below the header are two tabs: "All Games" and "Queue".

## Adding games from All Games

The "All Games" tab is a grid of your owned games (with a sort dropdown above it) — each card shows
the game's thumbnail, its name, and a small icon-only button in the corner: a plus icon if it isn't
queued yet, or a checkmark if it already is. Clicking it toggles that game in or out of the queue.

## Managing the queue

The "Queue" tab shows the games you've added as a grid of draggable cards. Each card has the game's
thumbnail and name, a toggle switch, and a remove button (an X icon). The switch controls whether
that game is actually included the next time idling starts — a game can stay in the queue without
being started, and a disabled card renders dimmed. Removing a card takes it out of the queue
entirely.

Cards can be dragged (click and hold, then drag) to reorder the queue — dropping updates the
persisted order immediately. While in the Queue tab (and it has at least one game), a "Clear"
button appears next to the tabs; clicking it opens a confirmation dialog ("Clear the automatic
idler queue? — This will remove all N games from the automatic idler queue.") before wiping the
entire queue.
