# Achievement Manager

This is source content for the AI Assistant's knowledge base (see `scripts/build-ai-corpus.mjs`),
generated by reading the actual `src/features/achievement-manager/` component code so the AI
Assistant can describe exactly what a user sees and clicks, not just what the feature does.
Regenerate this file (via the `/generate-ui-guide achievement-manager` skill) whenever this
feature's UI changes in a way that would make the description below inaccurate.

Achievement Manager is the single-game overlay for viewing and editing one game's achievements and
statistics directly (as opposed to the Achievement Unlocker, which automates unlocking across a
queue of games). It opens as a full-screen modal over whichever page you were on, with the game's
own hero/background art faded in behind everything.

## Opening the overlay and its header

The overlay's header has a back/close button (an X) on the top-left, the game's name next to it, and
two small icon buttons: a Steam icon ("View on Steam") that opens that game's Steam Community
achievement page in your browser, and a SteamDB icon ("View on SteamDB") that opens its SteamDB
stats page. Next to those sit two tabs, "Achievements" and "Statistics". On the right side of the
header is a search box that filters whichever tab is currently active by name. If the game has any
"protected" achievements or statistics, a warning banner appears below the header row: "Some items
are protected — Achievements or statistics marked as protected are set by the game's server and
can't be changed by clients."

## Viewing and toggling achievements

The Achievements tab shows a trophy icon with an "X / Y unlocked" readout and a small progress bar
next to it (both turn gold once every unlockable achievement is unlocked). Below that is a toolbar
with a sort dropdown, an "Unlock all" button, a "Lock all" button (red), and a circular refresh
button.

Each achievement is its own card row containing, left to right: a checkbox, the achievement's icon
(a small badge in the icon's bottom-right corner shows a green checkmark if unlocked or a grey lock
if not), the achievement's name with a rarity badge next to it when global unlock-rate data is
available (a percentage plus a tier word — Common, Uncommon, Rare, Epic, or Legendary, each in its
own color), its description underneath, and on the far right either an "Unlock"/"Lock" button (a
padlock icon, green to unlock or red to lock) or, for a protected achievement, a disabled ban-icon
button with a tooltip explaining it's set by the game server and can't be changed by clients.
Hidden achievements that aren't yet unlocked have their description blurred until you hover over it.

The checkbox on each row is a staging control, not an immediate action: an already-unlocked
achievement's checkbox starts checked, and unchecking it stages that achievement to be locked; a
locked achievement's checkbox starts unchecked, and checking it stages it to be unlocked. Protected
achievements have their checkbox disabled entirely. Once at least one achievement is staged, an
"Apply changes (N)" button appears in the toolbar — pressing it (after confirming in a dialog) locks
and/or unlocks every staged achievement in one pass and clears the staged set. Pressing an
individual row's own Unlock/Lock button instead applies that one achievement immediately and clears
it from any staged set.

"Unlock all" and "Lock all" each open a confirmation dialog ("Unlock all achievements?" / "Lock all
achievements?") before acting on every unprotected achievement in the game — they're disabled when
there's nothing left to unlock or lock, respectively.

## Viewing and editing statistics

The Statistics tab shows a count of the game's statistics and, once you've changed any, an "N
edited" pill next to it. The toolbar has a "Save changes" button (disabled until something's
edited, and labeled "Save changes (N)" once something is), a red "Reset all" button, and a refresh
button.

Each statistic is a card row: an icon (a small trending-up badge appears in its corner, with a
tooltip reading "This statistic can only increase, never decrease," for increment-only stats), the
stat's name with its raw flags text underneath, and a numeric stepper input on the right for editing
its value directly. A stat you've changed gets an "Edited" pill next to its name and a highlighted
border. A protected statistic shows its current value in a plain read-only pill with a ban icon
instead of an editable input.

Editing values doesn't save anything by itself — nothing is written until you press "Save changes,"
which applies every edited value in one pass and clears the edited set on success. "Reset all" asks
for confirmation ("Reset all statistics? — This will reset every statistic for this game back to
its default value. This can't be undone.") before resetting every statistic to its default.
