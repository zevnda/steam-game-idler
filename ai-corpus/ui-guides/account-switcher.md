# Account Switcher

This is source content for the AI Assistant's knowledge base (see `scripts/build-ai-corpus.mjs`),
generated by reading the actual `src/features/account-switcher/` component code so the AI
Assistant can describe exactly what a user sees and clicks, not just what the feature does.
Regenerate this file (via the `/generate-ui-guide account-switcher` skill) whenever this feature's
UI changes in a way that would make the description below inaccurate.

## Opening the switcher

The account switcher lives at the bottom of the sidebar as a row showing the active account's
avatar, its display name, and a small down-chevron on the right. Clicking it opens a popover above
it listing every signed-in account. When the sidebar is collapsed to its compact icon rail, this
row shrinks to just the avatar (hovering it shows the account name in a tooltip) — the popover
contents are identical either way.

## Reading an account row

Each row in the popover shows an avatar, the account's persona name (or its username/Steam ID if
that hasn't resolved yet), and a small label underneath reading either "Signed in with Steam"
(agent-mode accounts) or "Local Steam client" (CLI-mode accounts). A small solid dot on the
avatar's bottom-right corner appears while that account has live automation running (idling, card
farming, or achievement unlocking). The currently active account's row has a soft highlighted
background.

A row can also show one of two other badges next to the mode label:

- A "GAMER" tier badge — this account is signed in but currently over your subscription's
  concurrent-account limit (e.g. after a downgrade). The row stays clickable, just dimmed; clicking
  it opens the upgrade screen instead of switching to it. It is never signed out automatically.
- A red "Signed in elsewhere" badge with a small triangle-exclamation icon — this account's session
  was taken over by a sign-in on another device or session, so its automation has been paused.
  Hovering the badge shows a tooltip explaining this. Clicking the row opens the "Signed in on
  another device" reconnect dialog instead of switching to it (see below).

Each row also has a sign-out icon (a door-with-arrow icon) on its far right. Clicking it signs that
account out — if it has no automation running, it signs out immediately; if it does, a confirmation
dialog titled "Sign out?" appears first, warning that this will stop the automation currently
running for that account.

## Switching accounts

Clicking anywhere on a row (other than its sign-out button) switches to that account, unless it's
over-cap or flagged for reauth (see above), in which case the click reroutes to the upgrade or
reconnect flow instead. While a switch is in progress the row's sign-out icon is replaced by a
small spinner. Switching always navigates you to the main games page and shows a toast confirming
"Switched to <name>". If the target is a local (CLI-mode) account and Steam isn't currently running,
switching is blocked with a warning toast and the app's Steam-required warning dialog appears
instead.

## Adding another account

At the bottom of the popover, below a thin divider, is an "Add another account" row with a plus
icon. Clicking it opens the "Add account" modal, which reuses the same sign-in building blocks as
the main sign-in screen: a landing step to choose Steam Sign-in (agent mode, via QR code or
username/password) or Legacy Sign-in (local Steam client mode), followed by that method's normal
credential/QR/guard-code/account-picker screens. A successful sign-in closes the modal, navigates
to the games page, and shows a toast reading "Added <name>".

Two things can restrict this screen:
- If you already have a local (CLI-mode) account signed in, the Legacy Sign-in option is disabled —
  only one local account can ever be active at a time.
- If you've reached your subscription tier's limit on concurrent Steam Sign-in accounts, the Steam
  Sign-in option shows the limit reached ("The [tier] plan allows N accounts signed in with Steam at
  a time. Sign out of one to add another, or upgrade for more.") and, for Casual/Free tiers, stays
  clickable with a tier badge that opens the upgrade screen instead of a sign-in form. Gamer-tier
  accounts that hit their own maximum see a plain disabled button instead, since there's no higher
  tier left to upsell.

## Reconnecting a "signed in elsewhere" account

Clicking a row flagged "Signed in elsewhere" (or its badge) opens the "Signed in on another device"
modal. It explains that the account was signed in elsewhere so its automation was paused, and that
Steam Sign-in only allows one active session per account — if you'd like to keep playing games
while Steam Game Idler runs at the same time, it suggests using Legacy Sign-in instead. It offers
two buttons:

- "Reconnect" — attempts to resume that same account's session using its saved sign-in, taking the
  session back from whichever device currently holds it. Shows a spinner while in progress, and an
  inline error banner if it fails.
- "Use a different sign-in method" — closes this dialog and opens the same "Add another account"
  modal described above, letting you sign that account in a different way (for example switching it
  to Legacy Sign-in).

The badge and dialog clear on their own once a reconnect actually succeeds; there's nothing to
manually dismiss.
