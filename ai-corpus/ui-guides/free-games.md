# Free Games

This is source content for the AI Assistant's knowledge base (see `scripts/build-ai-corpus.mjs`),
generated by reading the actual `src/features/free-games/` component code so the AI Assistant can
describe exactly what a user sees and clicks, not just what the feature does. Regenerate this file

would make the description below inaccurate.

Free Games is a page listing games Steam is currently offering for free that you don't already
own, with a one-click claim per game.

## Page layout and header

The header shows the page title, a "N free games available" (or "No free games right now")
subtitle, a circular refresh button, and a settings (gear) icon that opens Free Games' tab in the
Settings modal.

## The game grid

Each card shows the game's thumbnail, name, and a "Claim" button. Clicking it claims that game for
your account — the button shows a loading state while in progress, then switches to a disabled
"Claimed" label once it succeeds. If the game turns out to already be owned, a small note appears
under the card: "You already own this game." If claiming fails outright, an error message appears
in red underneath instead. When there's nothing currently free, the page shows an empty state:
"No free games right now — Check back later — Steam periodically offers games for free."

## Settings

Free Games' settings tab (opened via the gear icon, or from the app's Settings modal) has two
toggles:

- **Free game notifications** — get a desktop notification whenever a new free game becomes
  available on Steam. This is an app-wide setting, not tied to a specific account.
- **Auto-redeem free games** — automatically claims newly-discovered free games for this account
  without needing to visit this page. This is Gamer-tier only — on lower tiers it stays a real,
  clickable switch with a "GAMER" tier badge that opens the upgrade screen instead of turning on.
  For a Steam Sign-in (agent-mode) account, this is a plain on/off switch. For a Legacy Sign-in
  (local Steam client) account, it's controlled by a pair of buttons instead — "Sign in to Steam" /
  "Reauthenticate" to establish the Steam Store session auto-redeem needs, and a "Sign out" button
  (disabled unless auto-redeem is currently on) to clear it.
