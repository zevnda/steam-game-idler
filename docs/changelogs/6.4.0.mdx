### New 🎉
- Polished the app's design throughout, making it cleaner and more consistent from page to page
  - Game cards now show each game's tall cover art, with its name along the bottom and its buttons appearing when you hover over it. If you prefer the old look, switch **Game card style** to **Banner art** in **Settings → Customization**
  - Game cards now show your playtime, achievement progress, and other useful information at a glance
  - The **Games** page opens with a new **Recommended** banner that cycles through a few of your unplayed games
  - The **Recently Played** row has been removed from the **Games** page, as it was redundant with the **Recently Played** sort options
- Redesigned the right-click menu to match the rest of the app, and added more useful options to it
  - Open **Custom Order & Unlock Delay** for any game, from any page
  - The new **Lists** menu shows which of your lists/queues a game is already in, and lets you add or remove it with one click
- Added a **Help** tab to **Settings** with answers to common questions, which you can easily search
- Added a new animated loading screen

### Improved 🚀
- Every page now has a slimmer toolbar at the top for its tabs and buttons
- Empty pages now explain how to get started, with a shortcut to do it
- Refreshed every color theme so buttons, inputs and selected items stand out clearly from the backgrounds where they appear
- The page you're on is now more clearly highlighted in the sidebar
- Text now fits properly in languages with longer wording, like Russian, Spanish and German

### Fixed 🐛
- Fixed **Max playtime** limits being applied incorrectly: **Card Farming** now respects them, and **Achievement Unlocker** only applies them to games it's actually idling, counting only the time spent idling
