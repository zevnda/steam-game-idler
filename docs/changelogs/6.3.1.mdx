### New 🎉
- Added **Completion** sorting options on all game list pages/tabs to sort games by their achievement completion percentages, so you can quickly find your most or least completed games
  - **Local Sign-in** needs your own Steam Web API key, added in **Settings → General**

### Improved 🚀
- Renamed **Legacy Sign-in** to **Local Sign-in** to better describe how it works: it uses the account already signed in to the locally running Steam client on your PC

### Fixed 🐛
- Fixed an issue where **Card Farming** could suddenly stop and mark every game it was farming as finished when Steam briefly had trouble loading your badges page
