### New 🎉
- Game names are now shown in your selected language when Steam has a translated name available for that game (not every game has one — this depends on what each developer has provided). Steam Sign-in uses the language set in **Settings → General**; Legacy Sign-in uses whatever language your local Steam client is set to

### Improved 🚀
- Switching languages while signed in with Steam Sign-in now automatically refreshes your games list so names update right away, instead of requiring a manual refresh
- Sorting games by title (A-Z / Z-A) now sorts correctly for your selected language instead of always using English alphabetical order
