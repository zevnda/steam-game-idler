### New 🎉
- Game names are now shown in the users' selected language when there is a translated name available for that game (not every game has one, it depends on what each developer has provided)
  - **Steam Sign-in** uses the language set in **Settings → General**
  - **Legacy Sign-in** uses the language your local Steam client is set to
- Search results and recent searches in the **Search** modal can now be navigated using the keyboard arrows, and pressing **Enter** will commit the highlighted result

### Improved 🚀
- Switching languages while signed in with **Steam Sign-in** now automatically refreshes your games list so names update right away
- Sorting games by title (A-Z / Z-A) now sorts correctly for your selected language instead of always using English alphabetical order
- Removed the need for users to provide a `sessionid` when enter ing their Steam credentials. SGI will now automatically generate one for you when needed
