### New 🎉
- Redesigned the **Card Farming** and **Achievement Unlocker** running screens, with clearer progress and more useful information
- When using **Steam Sign-in**, **Card Farming** now offers to set your status to **Offline** before starting, to help prevent spamming your friends with "started playing" notification
- Added support for the **Polish** language. If you'd like to translate SGI into your language or improve existing translations, see the [contribution guide](<https://github.com/zevnda/steam-game-idler/discussions/148>)

### Improved 🚀
- **Card Farming** and **Inventory Manager** now strictly require **Family View** to be turned off
- Minor improvements to the UI of **Custom Order & Unlock Delay** to make it easier to understand

### Fixed 🐛
- Fixed **Achievement Unlocker**'s **Only unlock during a schedule** setting to show AM/PM
