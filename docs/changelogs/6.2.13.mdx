### New 🎉
- Added 17 new animated **Signature Themes** for PRO subscribers in **Settings → Customization**. Each one brings a live animated background and its own accent color to SGI

### Improved 🚀
- In **Achievement Manager** and **Custom Order/Unlock Delay**, SGI now recognizes archived achievements, which a game's developer has retired so nobody can earn them anymore

### Fixed 🐛
- Fixed an issue on Windows where the SGI window got a little taller every time you quit and reopened the app, instead of keeping the size you left it at
