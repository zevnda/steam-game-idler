### Improved 🚀
- On **Windows**, updates no longer ask for administrator permission
  - Your accounts, settings, taskbar pins carry over automatically
  - After updating, SGI shows a one-time **Remove old files?** prompt to clean up what the previous version left behind. Click **Remove** and approve the Windows prompt one last time, or choose **Remind me later**. [Learn more](<https://steamgameidler.com/docs/troubleshooting#remove-old-files>)
  - If other people use SGI on the same PC with their own Windows account, they'll need to install it themselves once the old files are removed
