### New 🎉
- Added support for the **Portuguese (Brazil)** language. If you'd like to translate SGI into your language or improve existing translations, see the [contribution guide](<https://github.com/zevnda/steam-game-idler/discussions/148>)
- Added a built-in **AI Assistant** that answers questions about using SGI — grounded in the app's own documentation and interface, with links to the relevant docs pages
  - Use the **AI Assistant** by clicking the robot icon in the titlebar

### Improved 🚀
- Improved the UI of the **Custom Order/Unlock Delay** feature in **Achievement Unlocker** to make it more intuitive. Each achievement is now shown as its own card, and the delay value input now appears as its own control positioned between the two achievements to make it clearer that the delay is applied between the two achievements
