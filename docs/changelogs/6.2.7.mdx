### Improved 🚀
- The **Custom Order/Unlock Delay** window in **Achievement Unlocker** now warns you when a game has protected achievements, since **Achievement Unlocker** skips these games

### Fixed 🐛
- Fixed an issue with **Steam Sign-In** where the account would be briefly shown as Online before switching to the status selected in **Settings > General > Online Status**
- Fixed an issue with **Automatic Idler** where if you have multiple accounts signed in, only the currently selected account would start idling its games when SGI launched
