# Special Flags

Some achievements and statistics have restrictions [set by the game's developer](https://partner.steamgames.com/doc/features/achievements#game_server_stats:~:text=Stats%20and%20achievements%20that%20are%20settable%20by%20game%20servers%20cannot%20be%20set%20by%20clients) that affect what you can change. These are indicated directly in the UI.

- **Protected:** Only the game's official servers can modify these. Protected achievements show a warning icon in place of the unlock/lock button and can't be selected
- **IncrementOnly:** This statistic can only increase in value. You can raise it from 5 to 6, but not lower it from 5 to 4
- **Hidden:** The achievement's description is blurred by default. Hover over it to reveal the text

For statistics, IncrementOnly stats are labeled **Only increases** next to their name, and protected stats show their value as a read-only warning chip instead of an editable field in the Statistics view.
