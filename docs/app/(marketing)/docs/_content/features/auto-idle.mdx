# Automatically Idle Steam Games on Startup

Automatic idler lets you build a list of games that SGI will start idling automatically every time it launches. Once configured, you don't need to manually start anything. SGI handles it in the background.

This works best when combined with [Run At Startup](/docs/settings/general#run-at-startup) and [Start Minimized](/docs/settings/general#start-minimized), so SGI launches silently at login and begins idling your games without any input from you.

<Callout type="info">
  You can idle a maximum of 32 games simultaneously, across every SGI feature combined. This limit is set by the Steam client.
</Callout>

## Setting Up Automatic Idler

<Steps>
  <Step>
    Click <MockButton type='auto-idle' /> in the sidebar
  </Step>

  <Step>
    Go to the <MockButton type='all-games' /> tab, hover over a game and click <MockButton type='context-add' /> to add it to your queue
  </Step>

  <Step>
    Switch to the <MockButton type='content' content='Queue' /> tab to review what you've added
  </Step>

  <Step>
    The next time SGI launches, the games in this list will be idled automatically

    Alternatively, click <MockButton type='start-manually' /> to start idling them right now without waiting for a restart
  </Step>
</Steps>

## Enabling and Disabling Individual Games

Hover over a game in the <MockButton type='content' content='Queue' /> tab to show a switch that turns it on or off without removing it from the list. Games that are switched off will be skipped when idling starts, both on launch and when using <MockButton type='start-manually' />.

This is useful when you want to temporarily pause idling a specific game while keeping it in your list for later.
