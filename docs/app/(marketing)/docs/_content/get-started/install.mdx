# Install

SGI supports **Windows** (10/11, 64-bit) and **Linux** (64-bit). Follow the steps below for your OS and install method.

## Windows Installer

<Steps>
  <Step>
    ### Download
    Download `Steam.Game.Idler_X.X.X_x64-setup.exe` from the [latest release](https://github.com/zevnda/steam-game-idler/releases/latest/) page on GitHub
  </Step>

  <Step>
    ### Install
    Run the installer and follow the steps of the installation guide
  </Step>

  <Step>
    ### Run
    After installation, you can launch SGI in one of three ways:
      * Select "Run Steam Game Idler" and click "Finish" when prompted
      * Run `Steam Game Idler.exe` from the installation directory
        * Defaults to `C:/Program Files/Steam Game Idler`
      * Use the desktop shortcut created by the installer
  </Step>
</Steps>

## Windows Portable

<Callout type='warn'>
    The portable version does not support automatic updates. You'll need to download and replace the executable manually for each new release
</Callout>

<Steps>
  <Step>
    ### Download
    Download `Steam.Game.Idler_X.X.X_x64-portable.zip` from the [latest release](https://github.com/zevnda/steam-game-idler/releases/latest/) page on GitHub
  </Step>

  <Step>
    ### Extract
    Extract the contents of the `portable.zip` file to any folder you want
  </Step>

  <Step>
    ### Run
    Open the folder and run `Steam Game Idler.exe`
  </Step>
</Steps>

## Linux

<Callout type='info'>
    Linux supports [Steam Sign-in](/docs/get-started/how-to-sign-in#steam-sign-in) only
</Callout>

<Callout type='info'>
    SGI needs a working OS keyring (the [Secret Service API](https://specifications.freedesktop.org/secret-service/latest/)) to securely store your session. This is preconfigured on most desktops, but if sign-in fails, or you get a "your Steam session isn't active anymore" error — see [this troubleshooting entry](/docs/troubleshooting#linux-keyring-secret-service)
</Callout>

<Callout type='warn'>
    The `.deb` / `.rpm` versions do not support automatic updates. You'll need to download and install the new package manually for each release
</Callout>

<Steps>
  <Step>
    ### Download
    Download the file matching your distro/format from the [latest release](https://github.com/zevnda/steam-game-idler/releases/latest/) page on GitHub:
    - **Debian/Ubuntu-based**: `Steam.Game.Idler_X.X.X_amd64.deb`
    - **Fedora/openSUSE-based**: `Steam.Game.Idler_X.X.X-1.x86_64.rpm`
    - **Any distro**: `Steam.Game.Idler_X.X.X_amd64.AppImage`
  </Step>

  <Step>
    ### Install
    * **deb**: 
      ```bash
      sudo dpkg -i Steam.Game.Idler_X.X.X_amd64.deb
      ```
    * **rpm**:
      ```bash
      sudo rpm -i Steam.Game.Idler_X.X.X-1.x86_64.rpm
      ```
  </Step>

  <Step>
    ### Run
    * **deb/rpm**: launch SGI from your desktop's application launcher
    * **AppImage**: make it executable and run it directly
      ```bash
      chmod +x Steam.Game.Idler_X.X.X_amd64.AppImage
      ./Steam.Game.Idler_X.X.X_amd64.AppImage
      ```
  </Step>
</Steps>
