# Install

SGI supports **Windows** (10/11, 64-bit), **Linux** (64-bit) and **macOS** (12 or later, Apple Silicon only). Follow the steps below for your OS and install method.

## Windows Installer

<Steps>
  <Step>
    ### Download
    Download `Steam.Game.Idler_X.X.X_x64-setup.exe` from the [latest release](https://github.com/zevnda/steam-game-idler/releases/latest/) page on GitHub
  </Step>

  <Step>
    ### Install
    Run the installer and follow the steps of the installation guide. SGI installs just for your Windows account, so neither installing nor updating needs administrator approval. Don't run the installer as administrator: if Windows asks for another account's password, SGI installs for that account instead of yours
  </Step>

  <Step>
    ### Run
    After installation, you can launch SGI in a few different ways:
      * Select "Run Steam Game Idler" and click "Finish" when prompted
      * Run `Steam Game Idler.exe` from the installation directory
        * Defaults to `%LOCALAPPDATA%\Steam Game Idler`
      * Use the desktop shortcut created by the installer
  </Step>
</Steps>

<Callout type='info'>
    Older versions installed to `C:\Program Files\Steam Game Idler` for every Windows account on the PC, which is why each update used to ask for administrator approval. When one of those updates itself, SGI moves to your account's folder and asks Windows once for permission to remove the old files (see [SGI asks to remove old files](/docs/troubleshooting#remove-old-files)). Each Windows account that uses SGI needs its own install
</Callout>

## Windows Portable

<Callout type='warn'>
    The portable version does not support automatic updates. You'll need to download and replace the executable manually for each new release
</Callout>

<Steps>
  <Step>
    ### Download
    Download `Steam.Game.Idler_X.X.X_x64-portable.zip` from the [latest release](https://github.com/zevnda/steam-game-idler/releases/latest/) page on GitHub
  </Step>

  <Step>
    ### Extract
    Extract the contents of the `.zip` file to any folder you want
  </Step>

  <Step>
    ### Run
    Open the folder and run `Steam Game Idler.exe`
  </Step>
</Steps>

## Linux

<Callout type='info'>
    Linux supports [Steam Sign-in](/docs/get-started/how-to-sign-in#steam-sign-in) only
</Callout>

<Callout type='info'>
    SGI needs a working [OS keyring](https://specifications.freedesktop.org/secret-service/latest/) to securely store your session. This is preconfigured on most desktops, but if sign-in fails, or you get a "your Steam session isn't active anymore" error — see [this troubleshooting entry](/docs/troubleshooting#linux-keyring-secret-service)
</Callout>

<Callout type='warn'>
    The `.deb` / `.rpm` versions do not support automatic updates. You'll need to download and install the new package manually for each release
</Callout>

<Steps>
  <Step>
    ### Download
    Download the file matching your distro/format from the [latest release](https://github.com/zevnda/steam-game-idler/releases/latest/) page on GitHub:
    - **Debian/Ubuntu-based**: `Steam.Game.Idler_X.X.X_amd64.deb`
    - **Fedora/openSUSE-based**: `Steam.Game.Idler_X.X.X-1.x86_64.rpm`
    - **Any distro**: `Steam.Game.Idler_X.X.X_amd64.AppImage`
  </Step>

  <Step>
    ### Install
    * **deb**: 
      ```bash
      sudo dpkg -i Steam.Game.Idler_X.X.X_amd64.deb
      ```
    * **rpm**:
      ```bash
      sudo rpm -i Steam.Game.Idler_X.X.X-1.x86_64.rpm
      ```
  </Step>

  <Step>
    ### Run
    * **deb/rpm**: launch SGI from your desktop's application launcher
    * **AppImage**: make it executable and run it directly
      ```bash
      chmod +x Steam.Game.Idler_X.X.X_amd64.AppImage
      ./Steam.Game.Idler_X.X.X_amd64.AppImage
      ```
  </Step>
</Steps>

## macOS

<Callout type='info'>
    macOS supports [Steam Sign-in](/docs/get-started/how-to-sign-in#steam-sign-in) only, and needs an Apple Silicon Mac (M1 or newer) running macOS 12 or later. Intel Macs aren't supported
</Callout>

<Callout type='info'>
    Unlike on Linux, there's no keyring to set up: SGI stores your session in the macOS Keychain
</Callout>

<Steps>
  <Step>
    ### Download
    Download `Steam.Game.Idler_X.X.X_aarch64.dmg` from the [latest release](https://github.com/zevnda/steam-game-idler/releases/latest/) page on GitHub
  </Step>

  <Step>
    ### Install
    Open the `.dmg` and drag **Steam Game Idler** into your **Applications** folder
  </Step>

  <Step>
    ### Allow it to open
    SGI isn't notarized by Apple, so macOS blocks it the first time you open it, saying it can't verify the app. Allow it once:
    1. Open SGI from your Applications folder and close the warning
    2. Open **System Settings** → **Privacy & Security**, scroll down to the message about Steam Game Idler, and click **Open Anyway** (on macOS 12 Monterey: **System Preferences** → **Security & Privacy** → **General**)
    3. Confirm when macOS asks again (it may ask for your password or Touch ID)

    Alternatively, remove the quarantine flag in Terminal:
    ```bash
    xattr -dr com.apple.quarantine "/Applications/Steam Game Idler.app"
    ```

    You only need to do this the first time you open SGI. After an update, macOS may also ask for your password so SGI can use its keychain item; click **Always Allow** (see [Troubleshooting](/docs/troubleshooting#macos-keychain-prompt))
  </Step>

  <Step>
    ### Run
    Launch SGI from your Applications folder, Launchpad or Spotlight
  </Step>
</Steps>
