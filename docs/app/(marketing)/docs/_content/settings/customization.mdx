# Customization Settings

You'll find these options under <MockButton type='context-cog' content='Settings → Customization' />.

## Disable Tooltips
Hide the small informational pop-ups that appear when hovering over elements in the app

Tooltips provide extra context for buttons and settings, but can feel repetitive once you're familiar with the app. Enable this to turn them off.

## Show Recommended Carousel
Show or hide the recommended games carousel on the **Your Games** page

The recommended carousel surfaces games in your library that you haven't played yet. Disable this if you prefer a cleaner view.

## Show Recently Played Carousel
Show or hide the recently played games carousel on the **Your Games** page

The recently played carousel shows the last few games you've run through Steam. Disable this if you don't need quick access to recent games.

## Font
Change the font used throughout the SGI interface *(non-default fonts require Pro Casual tier)*

Every font is bundled with the app, so switching never needs a download. Pro fonts are unlocked with a [Casual or Gamer subscription](/pro).

## Background Image
Set a custom background image for the SGI window *(Pro Casual tier)*

Click <MockButton type='content' content='Choose image' /> to upload any common image file (PNG, JPG, WEBP, etc.) from your computer to use as a background. It's applied as a subtle overlay behind the main UI. Click <MockButton type='clear' /> to remove it and return to the default appearance.

## Theme
Change the color scheme of SGI *(non-default themes require Pro Casual tier)*

The theme picker has two rows: the animated **Signature Themes** on top, and the plain **Color Themes** below them. Click any swatch to preview and apply it immediately, no restart needed. Pro themes are unlocked with a [Casual or Gamer subscription](/pro).

### Signature Themes
Each signature theme gives SGI a live animated background and its own accent color. There are 17 of them, all *Pro (Casual tier)*:

Synthwave, Aurora, Nebula, Terminal, Ember, Abyss, Sugar Day, Sugar Night, Sakura, Lo-fi Rain, Fireflies, Holo, Black Hole, Lava Lamp, Circuit, Luxe and Arcade. Sugar Day is the only light one.

<Callout type="info">
    The animated background is kept light on resources, since SGI often runs for hours while idling:

    - It pauses on its current frame whenever the SGI window isn't focused, and stops entirely while SGI is minimized or in the tray
    - If your system has animations turned off (reduced motion), it shows a still frame instead of moving
    - On hardware that can't keep it smooth, it switches to a still frame for the rest of that session
    - Without graphics acceleration, the theme still applies its colors, just without the animated background
</Callout>
