# Card Farming Settings

You'll find these options under <MockButton type='context-cog' content='Settings → Card Farming' />.

## Hours Until Farmable
How many hours of playtime a game needs before its card drops are considered reachable

See [How It Works](/docs/features/card-farming/how-it-works) for more information on how this setting affects farming behavior.

## Farm Multiple Games At Once
Farm up to 32 games concurrently instead of one at a time. In some cases this can cause cards to drop significantly slower.

## Automatically Farm Cards
Periodically check for owned games with card drops remaining and automatically start farming them *(Pro Gamer tier)*

When enabled, SGI monitors your library on a recurring schedule and starts a farming cycle without you needing to trigger it manually.

## Skip Refundable Games *(Steam Sign-in only)*
Don't farm a game while it's still inside Steam's refund window

Skips farming any game bought within the last 14 days that has under 2 hours of playtime, since Steam considers it still eligible for a refund.

## Skip Unplayed Games
Skip games that have never been played *(0 playtime)* during card farming

<Callout type="info">
  **Skip Unplayed Games** and **Unplayed Games Only** are mutually exclusive: enabling one will disable the other.
</Callout>

## Unplayed Games Only
Only farm cards for games that have never been played *(0 playtime)*

<Callout type="info">
  **Skip Unplayed Games** and **Unplayed Games Only** are mutually exclusive: enabling one will disable the other.
</Callout>

## Start Another Task When Done
Automatically start another feature once Card Farming finishes

Enable the checkbox and choose either **Achievement Unlocker** or **Auto-Idle** from the dropdown to have it start automatically once your current farming cycle completes.
